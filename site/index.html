Fonctionnalités

Tout est automatisé

Une seule application Windows s'occupe de tout, du téléchargement de l'ISO jusqu'au système de secours.

📡

Téléchargement officiel

Récupère et vérifie (SHA-256) l'ISO Arch Linux directement depuis les miroirs officiels.

🥾

Sans clé USB

Démarrage préparé directement depuis le disque dur via GRUB (loopback) et une entrée UEFI dédiée.

🎨

Personnalisation

Nom de PC et utilisateur préconfigurés automatiquement, sans toucher au reste de l'ISO.

🚑

Système de secours

Une partition de réparation dédiée est créée avec sa propre entrée dans le menu de démarrage.

🇫🇷

Tout en français

Interface, scripts d'installation et raccourcis, entièrement en français avec des emojis.

🔧

Raccourcis pratiques

Mise à jour, installation de logiciels, infos système... accessibles en un clic après l'installation.

Aperçu

Une vraie interface, pas un script en ligne de commande

Panneau latéral avec le logo Arch Linux, puis une pluie Matrix plein écran pendant l'installation.

Installation

Comment ça marche

Quatre étapes, aucune clé USB.

1

Lance l'application sur Windows

En tant qu'administrateur : télécharge, personnalise l'ISO et prépare le démarrage sans clé USB.

2

Redémarre

Choisis l'entrée Fritax - Installer Arch Linux 🐧 dans le menu de démarrage.

3

Installation automatique

Lance scripts/install_arch.sh : partitionnement, installation, GRUB, système de secours. Une confirmation explicite est demandée avant d'effacer le disque.

4

C'est prêt !

Utilise les raccourcis ~/raccourcis-fritax.sh pour les tâches courantes.

Raccourcis

Après l'installation

Un petit menu en français pour les commandes du quotidien.

🔄 Faire une mise à jour sudo pacman -Syu
📦 Installer un logiciel sudo pacman -S ...
🧹 Nettoyer le cache sudo pacman -Sc
🌐 Adresse IP ip a
🖥️ Infos système neofetch
🚑 Démarrer sur le secours reboot --boot-loader-entry=...
⚠️ Remplace entièrement Windows — sauvegarde tes fichiers avant d'installer.
